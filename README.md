# うちのこ相性診断 — 公開用版

静的な HTML / CSS / JavaScript だけで動く相性診断です。ビルド作業は不要です。

## ローカルで確認

`index.html` をブラウザで開けば確認できます。

ブラウザによってローカルファイルの挙動が気になる場合は、このフォルダで次を実行してください。

```bash
python3 -m http.server 8000
```

その後 `http://localhost:8000` を開きます。

## 現在の仕様

- 名前入力
- 8問4択
- 5軸：柔軟性 / 積極性 / 自立性 / 行動志向 / 刺激志向
- 6キャラクターの重み付き相性計算
- 由井の能力ゲート
- 橘・鶴水・由井の特殊能力補正
- 1位＋2位＋3位表示
- X用シェアボタン
- 「診断の内訳を見る」
- 回答者と1位キャラ本人の5軸比較グラフ
- 結果セリフ・キャラ説明

## 計算ロジック

1. 各回答の0〜10の軸スコアを集める
2. 軸ごとの平均で回答者の5軸を作る
3. `10 - |回答者の値 - キャラ理想値|` を軸類似度とする
4. キャラごとの重要度で重み付き平均し、0〜100の基礎相性を作る
5. 能力ゲート・特殊補正を適用して最終相性にする
6. 最終相性順に並べる

### 特殊ルール

- 由井：有能またはバイタリティがないと1位候補にならない。片方で+8、両方で+12
- 橘：基礎80以上かつマネジメントONで+8
- 鶴水：基礎80以上かつバイタリティONで+10、基礎75以上かつマネジメントONで+5
- 最終点は100点上限

## 結果画像の差し替え

結果画像は現在プレースホルダーです。画像が揃ったら `assets/results/` に置き、`data.js` の各キャラクターの `image: null` を変更します。

例：

```js
image: 'assets/results/nayuki.png'
```

## 編集場所

- 質問・配点：`data.js` の `QUESTIONS`
- キャラ理想値・重要度：`data.js` の `CHARACTERS`
- キャラ本人値・結果セリフ・結果説明：`data.js` の `CHARACTERS`
- 両極ラベル：`data.js` の `AXES`
- 能力補正：`data.js` の `rules`
- 計算：`engine.js`
- UI：`index.html`, `styles.css`, `app.js`

## GitHub → Cloudflare Pages

このフォルダの中身を GitHub リポジトリのルートへアップロードします。Cloudflare Pages では GitHub リポジトリを接続し、静的サイトとしてデプロイします。フレームワークのビルドは不要です。


## 結果共有URL

公開環境（https）では、シェアボタンが以下の形式で投稿文を作ります。

`【江頭家相性診断】○○さんと相性がいいのは○○でした！`

その下に、`name` と8問分の回答コードを含む結果URLが付きます。共有URLを開くと質問画面を飛ばし、同じ回答から結果画面を自動再現します。

例: `https://example.pages.dev/?v=1&name=○○&answers=CCBBBBBD`

ローカルの `file://` で開いている間は公開URLが存在しないため、シェア文にはURLを付けません。Cloudflare Pagesに公開した後は自動で公開URLが入ります。
